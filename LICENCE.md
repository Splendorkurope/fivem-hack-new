4. Run the loader **as Administrator**.

5. Press `F4` or `Insert` to open the menu.

6. Toggle features ON/OFF.

> **Note:** If the menu does not appear, ensure the game is running in **Windowed** or **Borderless Windowed** mode.

## ⚙️ Configuration

Settings are stored in `config.json` at `%APPDATA%\FiveMHack\config.json`.

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"F4"` | Key to toggle menu |
| `process_name` | String | `"FiveM.exe"` | Target process |
| `esp_enabled` | Boolean | `true` | Enable ESP overlay |
| `aimbot_enabled` | Boolean | `false` | Enable aimbot |
| `safe_mode` | Boolean | `true` | Restricts risky features |
